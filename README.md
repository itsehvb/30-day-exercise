# 30-Day Knee & Posture Program

A one-page, phone-friendly workout site. Open `index.html` or the GitHub Pages link.

To update: edit `index.html` (exercise text is in the `KNEE`, `POST`, `HABITS` and `SAFETY` lists), then commit and push. If you change or add files in `images/`, also bump `CACHE` in `sw.js` (for example `ex30-v2`) so phones download the new files.

Videos and photos: Pexels (free to use); credits are on the Safety page.
